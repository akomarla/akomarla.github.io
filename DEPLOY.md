# Deploying and getting indexed

## 1. Upload

Replace the contents of the `akomarla.github.io` repository with everything
in this folder. Delete the old `index.html` first so nothing stale is left
behind. The files that must be at the repository root:

    index.html          publications.html   datasets.html
    awards.html         talks.html          speaking.html
    writing.html        mentorship.html     experience.html
    404.html            style.css           robots.txt
    sitemap.xml         google1f5443c871bae09b.html

GitHub Pages serves them automatically within about a minute. `404.html` is
picked up by GitHub Pages as the custom not-found page with no configuration.

## 2. Add your CV

The About page links to `cv.pdf`. Upload your CV to the repository root with
exactly that filename, or remove that one link from `index.html`.

## 3. Submit to Google (this is the step that actually gets you indexed)

Ownership verification is already handled: `google1f5443c871bae09b.html` is
included above. Leave it in the repository permanently, since Google
re-checks it, and do not rename it.

1. Confirm it loads at
   https://akomarla.github.io/google1f5443c871bae09b.html
2. In Search Console, on the URL prefix property for
   `https://akomarla.github.io/`, click **VERIFY**
3. Open **Sitemaps** in the left sidebar and submit `sitemap.xml`
4. Open **URL Inspection**, paste `https://akomarla.github.io/`, and click
   **Request indexing**. Repeat for `publications.html`

Indexing typically takes a few days to two weeks after this.

## 4. Build inbound links

Google weighs links from other sites heavily, and yours currently has almost
none. The highest-value places to add the URL, roughly in order:

- Google Scholar profile: add it as your Homepage
- LinkedIn: Contact info, Website field
- GitHub profile: the Website field on github.com/akomarla
- Your Duke Law fellow page and any Redo.io "team" or "about" page
- Conference speaker bios (INFORMS, APPAM, ICAIL) where you can still edit them

## 5. Updating the site later

The pages were generated by `build_site.py`, but they are plain HTML. Edit
them directly in GitHub. All nine share `style.css`, so a design change is a
one-file change. When you add a page, add it to the nav block in every page
and add a `<url>` entry in `sitemap.xml`.

Rerunning `build_site.py` regenerates the Google verification file as well,
so a rebuild never costs you your Search Console verification.
